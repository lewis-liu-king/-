# 航空部件生命周期与维修管理系统 - Verification Checklist

## 数据库设计验证
- [ ] 至少包含 6 张核心数据表
- [ ] 区分部件型号（ComponentModel）与部件实例（Component）
- [ ] 体现生命周期与历史记录设计
- [ ] 使用时间区间（start_time + end_time）表示安装记录有效性

## 完整性约束验证
- [ ] 主键约束正确实现
- [ ] 外键约束正确实现
- [ ] 唯一约束正确实现（部件编号唯一性等）
- [ ] 检查约束正确实现（时间合理性等）
- [ ] 关键业务规则在数据库层保证

## 业务逻辑验证
- [ ] 部件入库功能正常，拒绝重复编号
- [ ] 部件安装功能正常，检查部件状态和唯一性
- [ ] 部件拆卸功能正常，保留历史记录
- [ ] 部件更换事务正常，失败可回滚
- [ ] 维修登记功能正常，关联真实部件
- [ ] 部件退役功能正常，退役后拒绝安装
- [ ] 飞行日志登记功能正常
- [ ] 生命周期追溯查询返回完整信息

## 非法操作拦截验证
- [ ] 安装退役部件被拒绝
- [ ] 重复安装同一部件被拒绝
- [ ] 物理删除核心业务数据被拒绝
- [ ] 时间不合理的操作被拒绝
- [ ] 状态不一致的操作被拒绝

## 事务和历史保留验证
- [ ] 至少 2 个事务场景正确实现
- [ ] 软删除/退役标记机制正确实现
- [ ] 历史保留机制正确实现，不覆盖旧记录

## 查询验证
- [ ] 至少 3 个复杂查询可正确执行
- [ ] 生命周期追溯查询功能完整
- [ ] 查询结果具有业务解释力
